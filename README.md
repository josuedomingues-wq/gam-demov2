# Demo Media - Google Ad Manager Demo

Versão 100% estática e pronta para GitHub Pages.

## Publicar
1. Suba estes arquivos na raiz do repositório.
2. GitHub → Settings → Pages.
3. Source: **Deploy from a branch**.
4. Branch: `main`.
5. Folder: `/ (root)`.
6. Salve.

Não precisa de Node, npm, Vite, React ou GitHub Actions.
